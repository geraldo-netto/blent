# Android third-party components

Android runtime libraries listed in [runtime-dependencies.json](runtime-dependencies.json)
use the [Apache License, Version 2.0](Apache-2.0.txt). The inventory records their
exact reviewed coordinates, artifact hashes and license metadata provenance;
metadata-only dependency entries have no binary artifact.

OkHttp includes public-suffix data under the
[Mozilla Public License, Version 2.0](MPL-2.0.txt).
Its [original notice](publicsuffix-NOTICE.txt) identifies the source location.
That notice also remains in OkHttp's original APK resource path.

Project [LICENSE](LICENSE) and [COPYRIGHT.md](COPYRIGHT.md) describe Blent and
inherited UScreen code. Their cross-project discussion of libevdi concerns the
host distribution; libevdi and FFmpeg are not bundled in this Android APK.
