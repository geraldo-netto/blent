## T1283 — GPU parameter-buffer retirement

`host/tests/gpu_lifecycle.c` injects `VA_STATUS_ERROR_OPERATION_FAILED` into
parameter-buffer destruction and requires helper exit 2. Before the fix the
helper returned successfully and the regression failed. `convert` now treats
unconfirmed destruction as fatal before further frame admission. The helper
process remains the cleanup sponsor for its native resources until exit.

All four existing GPU fixture targets pass with ASan/UBSan/leak detection on
private Xvfb in the installed offline Freedesktop SDK 26.08. This uses the same
test-only FFmpeg profile-name spelling substitution documented in the review;
physical driver behavior is not inferred from fixtures. GCC gcov measures
`convert` at 13/13 executable lines. The repository complexity metric with
tree-sitter 0.25.2 measures all functions in both changed files at <=9.
Evidence: `t1283-red.log`, `gpu-results.json`, `t1283-metrics.json`.

## T1284 — Final capture registration

The permanent T1284 native fixture owns registration nodes and reads borrowed
storage during unregister. Four subprocess cases cover no mode, native storage,
canonical/native storage pairs and allocation failure. Before the fix, normal
shutdown failed the live-registration assertion. Shutdown now unregisters after
writer/conversion quiescence and before freeing storage or closing libevdi.
All 104 native helper cases pass with ASan/UBSan/leak detection; gcov measures
shutdown_capture at 21/25 executable lines (84%). The repository complexity
metric measures every function in the four changed code files at <=9. Evidence:
t1284-red.log, evdi-results.json and t1284-metrics.json. Native driver quiescence
is not established by this userspace fixture; synchronous grabs/event-loop exit
remain the production boundary, as documented in the review.
