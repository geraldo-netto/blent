## T1283 — GPU parameter-buffer retirement

`host/tests/gpu_lifecycle.c` injects `VA_STATUS_ERROR_OPERATION_FAILED` into
parameter-buffer destruction and requires helper exit 2. Before the fix the
helper returned successfully and the regression failed. `convert` now treats
unconfirmed destruction as fatal before further frame admission. The helper
process remains the cleanup sponsor for its native resources until exit.

All four existing GPU fixture targets pass with ASan/UBSan/leak detection on
private Xvfb in the installed offline Freedesktop SDK 26.08. This uses the same
test-only FFmpeg profile-name spelling substitution documented in the review;
physical driver behavior is not inferred from fixtures. GCC gcov measures
`convert` at 13/13 executable lines. The repository complexity metric with
tree-sitter 0.25.2 measures all functions in both changed files at <=9.
