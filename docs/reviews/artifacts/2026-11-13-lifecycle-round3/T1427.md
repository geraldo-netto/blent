# T1427 — recover failed activity-property refreshes

Linux native activity refresh now returns explicit errors for failed/expired
queries, owner loss and invalid property values. `Actor::apply_signal` propagates
those failures into the existing actor-loss and follower-replacement workflow.
An invalidation first publishes unknown, so demand stays conservative while the
original actor stops and its native completion settles. Only then may the follower
create a fresh epoch. Successful snapshots and stale-sequence filtering retain
their existing semantics; a valid compositor unknown value remains distinct from
a failed query.

No new resource owner, retry loop, capacity or lifetime is introduced. Actor task,
source lifetime and follower attempt retain the same original proofs on error,
stop and cancellation. Unknown obligations remain funded; a failed query does not
permit identity reuse or erase a held native receipt.

## Permanent validation

Two T1427 tests were added before the production change. `T1427-red.log` records
both failing because failed refresh never reaches source loss/recovery. The
independent public-API reproduction in `linux/refresh-failure.log` proves the
actual stuck publication and successful same-owner query; timeout alone is not
the causal evidence.

The first regression covers both lock and display invalidation, query failure,
held original native debt, and fresh-epoch recovery. It asserts no second creation
before the exact original completion settles. The second keeps display queries
failing across multiple replacement attempts, verifies conservative publication,
and stops/settles all original attempts without further creation. Existing T1413
and T1418 owner/transport loss, capability continuity, unsupported startup,
retained cancellation and explicit-stop regressions remain included.

`T1427-green.log`: 54/54 selected activity-related library tests pass.
`T1427-coverage.log`: 68/68 instrumented selections pass (activity54,
follower11, activity-view3). These are test counts, not platform support claims.
All tests use private buses/fake fixtures; no physical suspend, EVDI, input-device,
