prompt identity, preparation/admission gates and logical cancellation. Camera
retains its independent typed profile/action boundary; native ownership,
credentials, OS permissions and actual retirement stay in their adapters.
Speaker policy never creates an SDK prompt. No microphone capability is enabled.

New permanent domain tests exercise microphone/camera/speaker leases, every
invalid lease counter and maximum valid counters, opaque foreign/reconstructed
and equal-counter replacement replies, fresh permission after callbacks, denial,
foreground/background and local intent, admission, revocation and held original
native authority. Closing the policy cannot prove native retirement.

Evidence uses cached offline dependencies and synthetic JVM/Robolectric APIs.
No downloads, installations, live USB/ADB, host services or physical tests.
Microphone permission composition is T997, Android uplink T998, Linux uplink T999
and automated duplex isolation T1000. Physical T859 remains explicitly deferred;
that decomposition does not complete acceptance. The inventory includes the
pre-existing uncommitted host TLS fixture, which is outside this commit.

Native per-method counters and authored constructor checks, complexity, source
fingerprints and full-suite results are retained with the matching inventory.

Final full suite: 1907 tests, 0 failures, 0 errors, 0 skips. All 2,724 maintained methods pass individual native 80% line coverage. Changed authored complexity: 82 functions, maximum 8.
