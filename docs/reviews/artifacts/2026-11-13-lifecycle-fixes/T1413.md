# T1413: recover terminated native D-Bus activity observers

`Actor::run` now requests source replacement after an error or panic in its
original observer. Normal explicit stop does not request replacement. The
existing follower drains loss evidence, stops the original source and waits
for its native completion before constructing a fresh epoch.

Permanent regressions are in `host/src/activity/recovery_tests.rs`, nested under
the existing private D-Bus fixture module. They compose the real `LinuxSource`
and D-Bus actors with `Following`, using private system/session connections.
They cover logind owner replacement, compositor owner replacement, connection
closure and explicit stop. Owner replacement additionally holds an independent
original native completion: no new factory call is permitted before settlement.
Fresh observations require a larger epoch; signals from the previous owner
cannot pause the replacement. The supplied connection is owned only by the
private fixture and source, and source stop closes the original actors before
the fixture is released. Retained completion values observe ownership without
granting commands or replacing the original native fence.

The existing T1008 sibling-backend test retains its original assertions. It now
waits until the sibling's signal is actually queued before polling it, then
asserts the new recovery error once the queue is empty. This avoids racing the
new terminal source notification; it neither removes the stale-owner assertion
nor treats lost source state as healthy.

  recovery cases failed and explicit-stop control passed.
- `T1413-green.log`: all four new cases passed after the change.
- `T1413-coverage.log`: 46/46 tests selected by `activity::` passed, including
  the strengthened permanent cases and existing activity/native lifecycle tests.
- `T1413-metrics.json`: changed production method `Actor::run` has 12/13
  executable lines covered (92.31%), complexity 2. The one uncovered line is
  a tracing-macro line, not excluded from the denominator.
- `T1413-complexity.json`: all new/changed methods, including tests, are <=5.

Coverage used Rust 1.100.0 native LLVM counters and cargo-llvm-cov 0.8.7. Profiles
were isolated in `/tmp/blent-t1413-profraw`; export used exactly the instrumented
library test object reported by Cargo, not all historical target objects.
Complexity used the project's locked syn 2.0.119 frontend. The source hash and
per-line counters are retained in the metric JSON and scoped LCOV artifact.

No production process, tablet, system bus, configuration or physical suspend state
was changed. Private fixtures establish these bounded adapter/follower transitions;
they do not claim physical suspend/resume or unrestricted native lifetime proof.
