# T1422 — retain original Linux input construction

Linux input now reserves a bounded backend admission before session preparation.
`InputBackend::native_completion` exposes that original proof to the existing
session native-retirement boundary before any follower starts. Input admission
also joins the process registry, so graceful exit retains the runtime until the
original constructor, device destruction and admitted OSK restoration settle.
Fallible admission propagates through Linux session preparation; current callers
handle the result rather than hiding exhaustion.

Each backend admits one follower. A separate identity lease remains exclusive
across distinct backends until original native debt settles. The native owner
holds completion observations, not duplicate device state. `DeviceOwner` owns
published devices; an owned blocking task owns construction until join. A bounded
oneshot transfers its result to the still-live follower. If cancellation drops
the receiver, the original constructor destroys the late result before its task
settles; it cannot republish to the stopped session. The original identity lease
remains with retirement until those task proofs complete. Input sinks retain an
empty device container after follower retirement, not native device authority.

`BLENT_INPUT_LIMIT` defaults to 64, accepts 1..4096 and rejects before native
creation. One backend funds one sequential constructor and one final OSK cleanup
observation. The process proof grant includes the input maximum: 12292 total
(session, route and input maxima of 4096 each plus four activity sources).
The registry still observes original proofs while pools own resource cleanup.
A permanent native stall retains bounded ownership and prevents graceful exit;
eventual cleanup assumes native completion and observer/runtime scheduling.
No backward-compatibility constructor wrapper or alternate lifetime is retained.

The permanent normal-suite `host/tests/input_creation.rs` uses the existing
fail-closed uinput shim, adds an explicit constructor gate, and checks its marker
before creating devices. Every file/descriptor is private to its child fixture.
The gate is released on assertion unwind before runtime join. No real uinput
descriptor is opened and no physical input, tablet, service or display is changed.
The initial regression failed before behavior edits because cancellation left
an admitted constructor without a native proof (`T1422-red.log`).
