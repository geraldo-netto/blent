Focused projection/control interfaces connect the portable local camera owner to
the retained run/runtime and serialized actor. Permission results resolve through
the original owner's opaque pending prompt. Current pairing and exact original
connection lease are required for consent and route visibility; local ownership
additionally checks pending expiry and actual protocol admission.

Camera publication emits only transitions, retains its metadata before callbacks,
and preserves offer-to-admission without closing that same lease. Closure revokes
visibility independently of display and actual native ownership. Original-owner
capture-consumer completion remains accepted after logical stop; new choices and
permission replies are rejected. Actor cleanup processes those bounded terminal
commands before evaluating actual joined retirement.

accept retained consumer proof, then passes unchanged. Tests cover opaque prompt

counters plus range edges, standalone display-only composition, publication failure,

production local TCP, camera management/mux/pumps, greeting/feedback and joined
retirement. Its explicit consumer proof means hardware was never started; socket
EOF alone does not release the claim. This is not actual camera/codec or physical

after disconnect; that prevented local cleanup from advancing. Correcting the
fixture preserves all actual-retirement assertions. It is separate from the
confirmed actor cancellation regression and is not claimed as a product fix.
