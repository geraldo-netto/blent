# About navigation (T1276)

Project links now live in a top-level About page. Header branding and navigation
remain stable when changing pages. About has no settings subnavigation or Save
controls, and visiting it preserves unsaved drafts. Link rows wrap on small
windows; reporting still opens a prefilled issue without submitting it.

The permanent T1276 tests first reproduced missing About navigation and a
40-point vertical shift between Tablets/Connections and Settings. After the fix,
152 GUI tests plus the native Xvfb/accessibility startup test pass. Keyboard
activation and 380/440/1040-point layouts are covered. Existing link-target
regressions remain in the suite, exercising the relocated controls.

All eight changed production functions have 100% executable-line coverage
(cargo-llvm-cov 0.8.7, LLVM 22.1.8, Rust 1.98.1). The locked syn 2.0.119 checker
measured 202 functions in the changed modules/tests, maximum complexity 9.
[Per-function evidence](artifacts/2026-10-27-about/t1276.json) retains source hashes.

Rendering borrows current app state for the frame; no new persistent state,
resource acquisition, worker or native handle was added. Existing egui owns
widget/layout memory. About navigation cannot start capture or release media
owners. The native Windows acceptance gap remains tracked by T1271.

## Offline license and attribution access (T1277)

About now shows copyable version/platform/build metadata, credits sourced from
COPYRIGHT.md, an MIT summary and a selectable offline viewer. The 64 embedded
documents include LICENSE, COPYRIGHT.md, THIRD_PARTY_LICENSES.md, every tracked
file under licenses/ and the Android assets/licenses/ notice set. Their contents
are included verbatim at compile time, rather than copied into another maintained
text. The normal suite compares the complete corpus against its authoritative
files and rejects missing/duplicate entries or drift. Missing include inputs
fail the build; the runtime viewer does not require repository files or internet.

The text distinguishes Blent's own MIT terms, individual third-party terms and
Android-only notices. Linux's explicit package-notice action locates the directory
relative to the executable, requires both the directory and manifest, and requests
an escaped local file URL only when available. It reports absence without asserting
that embedded notices account for the entire installation. Windows explicitly
reports its preview lookup limit. T1278 records the separately discovered missing
bundle notice directory in this machine's existing extracted installation; this
change neither reconstructs that package's provenance nor claims full distribution
license compliance. No browser, issue submission or network request occurs merely
by viewing About.

BLENT_BUILD_REVISION is optional compile-time metadata supplied by the builder.
Unspecified builds honestly show “not recorded”; the field is not an attestation.

Ownership is stateless apart from egui-owned bounded selection/error state.
Embedded texts have static process lifetime: 64 documents, each <=256 KiB and
<=2 MiB total, enforced permanently in the suite. Invalid selection indices are
clamped before access. The frame borrows texts; clipboard output owns its requested
copy under egui's existing event lifecycle. Native path lookup retains no handles,
workers or callbacks and changes no files. Navigation leaves capture and media
ownership untouched. Tests cover every document, extreme indices, all byte values
in Linux file-URL escaping, absent manifest/directory, retry, source consistency,
clipboard content, keyboard access and small-window selection/reading. The About
content regression failed before implementation; the long picker-path regression
failed before wrapping was added. Both remain in the normal automated suite.

Final T1277 verification: 161 Linux GUI unit tests plus native Xvfb/accessibility
startup pass. All 11 changed Linux production functions have 100% executable-line
coverage; the Windows-only notice adapter has no native counters and remains
explicitly unavailable under T1271. Windows tests cross-compile offline, including
its permanent preview-limit test. The locked syn checker measures 209 functions
in the changed modules/tests, all <=9. Tool versions match T1276 above.
[Per-function evidence](artifacts/2026-10-27-about/t1277.json) retains the unavailable
Windows result rather than claiming an all-platform coverage pass.
