remain stable when changing pages. About has no settings subnavigation or Save
controls, and visiting it preserves unsaved drafts. Link rows wrap on small
windows; reporting still opens a prefilled issue without submitting it.

measured 202 functions in the changed modules/tests, maximum complexity 9.

widget/layout memory. About navigation cannot start capture or release media
owners. The native Windows acceptance gap remains tracked by T1271.
